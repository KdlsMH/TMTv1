# Task Message Studio - HTML Applied UX Version

업로드된 `task_message_studio.html`의 UI 방향을 기존 프로젝트에 적용한 버전입니다.

## 적용 내용
- 기존 프로젝트의 `index.html`, `js/app.js`, `js/generator.js` 기능 유지
- 관리자 화면: 흰색 배경, 로열블루 상단 라인, 폼형 카드 UI 적용
- 작업자 화면: 미리보기 화면을 더 분리된 작업 패널 형태로 정리
- 요청자가 `작업 링크 생성하기`를 누르면 작업자 전용 링크 생성
- 작업자 링크 접속 시 요청자 메뉴 없이 작업 안내 → 수행 → 완료 흐름만 표시
- 서버에서 불러온 작업도 완료 결과에 제목, 보상, 메시지 등 원본 설정을 유지
- 초기 화면에서 결과·더미 데이터를 숨기고 명확한 빈 상태 제공
- 데이터 유형, 복잡도, 민감정보, 판단 명확성, 주관성, 데이터 양을 함께 반영한 부담 점수 제공
- 단일·전체 제한 시간, 작업당·전체 예상 시간, 예상 작업 수, 휴식 포함 여부를 분리 표시
- 자율성·유능감·관계성 프레임을 균형 있게 제공하고 작업자 선택권 설정 지원
- 분석 중 설정 수정 및 현재 요청 취소 후 재분석 지원
- 기본 입력은 간단하게 유지하고 고급 작업 조건은 펼쳐서 조정
- 극단값을 평균화하지 않고 조건 충돌 시 경고와 대안을 생성하도록 프롬프트 보완
- 각 입력 블록 우측 상단의 작은 `예시` 버튼에서 마우스 올림·키보드 포커스·모바일 클릭으로 작성 형식 확인
- 상세 가이드라인 입력칸 우측 상단의 초소형 `형식` 버튼에서 `##`, `###`, `**강조**`, 번호 목록 예시 확인
- 기존 ID/class 구조 유지: 기존 JS 연결이 끊기지 않도록 처리
- 작업자 탭 진입 시 `body.worker-mode` 자동 적용
- 화면 문구에서 과도한 LLM/AI 느낌을 줄이고 서비스형 문구로 정리

## 실행 방법
1. 압축 해제
2. `index.html`을 브라우저로 열기
3. 관리자 생성 화면에서 입력 후 `안내 메시지 만들기` 클릭
4. `작업 링크 생성하기`를 눌러 생성된 URL을 작업자에게 전달
5. 작업자는 링크에 접속해 안내를 확인하고 작업 수행
