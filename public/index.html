Task Message Studio

더 나은 작업 메시지를 넘어,더 나은 크라우드워크를 설계하세요.

Worker의 내재적 동기와 작업 경험까지 고려하는 Crowd Task Message Design System

Task Message Studio는 Worker가 작업의 의미와 자신의 기여를 이해할 수 있도록, Task 특성에 맞는 작업 전후 커뮤니케이션을 설계합니다.

Why do we do a task?

우리는 왜 일을 할까요?

어떤 일은 그 자체가 재미있거나 만족스러워서 합니다.
어떤 일은 보상이나 결과를 얻기 위해 합니다.

Intrinsic Motivation

내재적 동기

일 자체에서 오는 동기

활동 자체에서 재미, 흥미 또는 만족을 느껴 스스로 하고 싶어서 행동하는 동기입니다.

Extrinsic Motivation

외재적 동기

외부의 결과에서 오는 동기

보상, 평가, 인정 또는 특정한 결과를 얻기 위해 행동하는 동기입니다.

Crowd Work Example

Crowd Work에서는 이렇게 나타날 수 있습니다.

“이 작업의 결과는 AI 데이터의 품질을 개선하는 데 활용됩니다.”

Worker는 자신의 작업이 필요한 이유와 기여의 의미를 이해할 수 있습니다.

“이 작업을 완료하면 보상을 받을 수 있습니다.”

Worker는 보상이라는 외부 결과를 고려해 Task에 참여할 수 있습니다.

What does this mean for crowd work?

그렇다면 Crowd Work에서는 어떨까요?

금전적 보상은 Crowd Work에서 중요합니다. Task Message Studio는 보상의 중요성을 부정하거나 대체하려는 시스템이 아닙니다.

대신 Worker가 작업을 단지 “보상을 받기 위해 해야 하는 일”로만 경험하지 않고, 자신의 판단과 작업의 의미, 기여를 이해할 수 있도록 작업 커뮤니케이션을 지원합니다.

그렇다면 Worker가 작업을 보다 자율적으로 경험하도록 어떻게 지원할 수 있을까요? Self-Determination Theory
What is Self-Determination Theory?

Crowd Worker의 작업 경험을 지원하는 세 가지 기본 심리 욕구

Self-Determination Theory(SDT)는 Autonomy, Competence, Relatedness가 충족될수록 활동에 자발적으로 참여하고 내재적 동기를 이어가기 좋은 조건이 형성된다고 설명합니다.

01

Autonomy 자율성

“내가 선택하고 판단할 수 있다.”

과도한 통제보다 Worker의 판단과 선택이 존중된다고 느끼도록 지원합니다.

02

Competence 유능감

“나는 이 일을 잘 해낼 수 있다.”

Worker의 판단과 기여 능력을 인정하고 효과적으로 수행할 수 있다는 감각을 지원합니다.

03

Relatedness 관계성

“내 작업은 누군가와 연결되어 있다.”

자신의 기여가 다른 사람이나 더 큰 목적과 연결된다고 느끼도록 지원합니다.

Why apply SDT to task messages?

메시지는 Requester와 Worker가 만나는 첫 번째 작업 경험입니다.

같은 작업이라도 어떻게 전달하는지에 따라 Worker가 경험하는 의미와 동기는 달라질 수 있습니다. Task Message Studio는 Task 특성을 먼저 분석하고, 필요한 SDT 요소를 선택하거나 우선순위를 조정한 뒤 Worker 메시지에 반영합니다.

SURVEY EVIDENCE

120 Crowdworker Survey

N=120

Based on a survey of 120 crowdworkers. The Core and Supporting Frames are determined from workers' preferred motivational framing for each task type.

Task TypeCoreSupporting3rd

1순위는 Core, 2순위는 Supporting으로 생성에 적용됩니다. 3순위는 참고용이며 메시지 생성에는 사용하지 않습니다.

Message Length
Survey Evidence (N=120)

66.7% of participants (80/120) preferred the medium-length message, compared with 14.2% for the short message and 19.2% for the long message.

Based on this result, the system uses a medium message length, operationalized as 4–5 sentences.
